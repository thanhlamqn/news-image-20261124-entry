## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies the pre-rendered
`entry.png` to the output directory. The image itself is drawn by
`render_news_image.py` (Pillow, build-time only) from news reported on
24 November 2026 by Reuters, AP, AFP, SCMP and The Japan Times.
